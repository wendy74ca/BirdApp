# BirdApp
Software-only collage of recent eBird sightings, inspired by Teddy Warner’s Avian Visitors (github.com/Twarner491/AvianVisitors). Includes drawings by Teddy Warner, CC BY-NC-SA 4.0.
## Credits

This project is a software-only adaptation of Avian Visitors by Teddy Warner
(https://github.com/Twarner491/AvianVisitors, https://avianvisitors.com).
The kachō-e collage idea and many of the bird drawings are his.

- Drawings by Teddy Warner are used under CC BY-NC-SA 4.0
  (https://creativecommons.org/licenses/by-nc-sa/4.0/). I resized them and
  built masks from them, but the artwork is his.
- Additional drawings were generated with Gemini by Wendy.
- Sighting data comes from eBird (Cornell Lab of Ornithology) via the eBird API.
  You need your own eBird API key.
